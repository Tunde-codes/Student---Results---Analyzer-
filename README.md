# Student---Results---Analyzer-
Student Result & Performance Analyzer

A beginner-friendly Python project for managing student results and analyzing class performance.

Features

- Add student records
- View saved student records
- Search for students by ID
- Validate scores
- Calculate student averages
- Assign grades and performance statuses
- Save student records using JSON
- Calculate class performance statistics
- Handle invalid input

Technologies Used

- Python
- JSON
- File Handling
- Dictionaries and Lists
- Functions
- Exception Handling

Purpose

This project was built to practise Python programming fundamentals through a practical student-result management system.

Future Improvements

- Display the student with the highest average
- Improve the user interface
- Add more class performance statistics
